# Snowbird Travel Co.

A travel page for INM420 (JavaScript Libraries assignment). Snowbird is a made-up agency that sells flight tickets to winter escapes away from Toronto.

## Libraries used

1. **Typed.js** - types out the destination names in the hero
2. **Glide.js** - carousel of destination cards
3. **Leaflet** - map with flight paths from Toronto
4. **Chart.js** - bar chart comparing winter temperatures with Toronto
5. **Fullscreen Lightbox (fslightbox)** - opens gallery photos full screen
6. **AOS (Animate On Scroll)** - fades sections in as you scroll



## Run it

```
npm i
npm start
```

Then open http://localhost:3000.
